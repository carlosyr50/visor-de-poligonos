# Visor de polígonos

Visor web de polígonos y lotes (versión parcial del visor que uso en local).

- Importa archivos `.json` con polígonos (arrastrándolos o con **Importar .json**) o prueba con **Ver ejemplo** (datos ficticios).
- Muestra área, perímetro, ángulos, centroide y coordenadas de cada polígono.
- Permite nombrar manzanas y lotes, marcar vías y colindantes, y ver el plano de cada lote (exportable a PDF).
- **Privacidad:** todo se procesa en tu navegador. Los archivos no se envían a ningún servidor; lo trabajado queda solo en el almacenamiento local de tu navegador (se borra con **Vaciar**).
- Funciona en PC y en celular.

Abrir: `index.html` (publicado con GitHub Pages).
